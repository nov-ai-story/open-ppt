# 一次确认

开始写页面前，把问题合并成一条消息。优先让用户回复「默认推荐」。

```text
开始前请一次性确认。可以直接回复「默认推荐」。

1. 演示对象：管理层 / 技术团队 / 产品团队 / 客户 / 混合
2. 演示目的：架构导读 / 项目复盘 / 成果汇报 / 方案评审
3. 输出形式：HTML / HTML + PNG 序列 / HTML + 多页 PDF
4. 时长或页数：不确定则按材料决定
5. 交互：静态翻页 / 键盘导航 / 点击展开
6. 比例：16:9 / 16:10 / 4:3（默认 16:9）
7. 导出分辨率：不导出 / 1K / 2K（默认要导出时用 2K）
8. 是否有品牌色、字体、参考页或封面图？

章节请标「保留 / 删除 / 暂不确定」：
- 难点与解决
- 方案对比
- 架构 / 数据流
- 项目沉淀 / 复用
- 团队推广
- 复盘
- 风险与下一步
```

## 决策

- 未回答时，架构导读用技能里的默认推荐。
- `保留` 必须有材料证据。
- `删除` 的章节不要在观众页暗示缺失。
- 没有量化指标时写机制和落地，不编数字。
- 没有复用资产时不要硬做 CBB 页。

内部决策表只放制作侧，不进观众页。
