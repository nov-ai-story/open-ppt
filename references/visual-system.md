# 视觉系统

默认复制 [../assets/deck-shell.html](../assets/deck-shell.html)。这是工程导读皮肤：纸色底、墨绿强调、深色间隔页、琥珀高亮。用户指定品牌色时替换 CSS 变量，不改舞台结构。

## 舞台

- 逻辑画布 `1280×720`，按视口等比缩放
- 宽屏保持横排；4:3 减少并排；`max-width: 860px` 改为纵向阅读
- 字体用 CJK 无衬线 + 等宽回退；禁止拉伸字体来填缝
- 浅色页顶条绿色，深色页顶条琥珀
- 交替浅/深，避免十一页同一张卡片墙

## 色板

| 变量 | 值 | 用途 |
|---|---|---|
| `--ink` | `#18201d` | 主文字 |
| `--paper` | `#f4f3ee` | 浅色页底 |
| `--green` | `#126b4b` | 主强调 |
| `--amber` | `#e7b83c` | 深色页强调、终点 |
| `--coral` | `#d65b45` | 警告 / 关键约束 |
| `--blue` | `#2f6d8a` | 编排 / 次级对象 |
| `--dark` | `#101613` | 深色页底 |

## 布局家族

每页只选一种主构图：

| 类名 | 用途 |
|---|---|
| `.cover` | 封面。可选 `--cover-image: url("cover.jpg")` |
| `.objects` | 5 个以内职责对象 |
| `.layers` | 自上而下分层 |
| `.tree` / `.field` | 输入契约 |
| `.pipe` / `.step` | 主链路站点 |
| `.seq` / `.seq-item` | 一次机制的步骤 |
| `.coords` / `.formula` | 坐标或公式 |
| `.costs` | CPU / 主线程 / GPU 或等价成本 |
| `.issues` / `.summary` | 排障表 + 收束链路 |

## 文案密度

- 标题是问题的结论，不是章节名
- 副标题 `kicker` 用一句判断
- 页脚放记忆钩子或限定条件
- `data-notes` 写讲法和源码位置

## 交互

保留壳里的行为：`← →` 翻页，`N` 备注，`?` 或 `?preview=1` 预览侧栏。新增交互必须可键盘使用，并尊重 `prefers-reduced-motion`。
